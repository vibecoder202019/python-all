# Career ladder — DevOps → Principal / Cloud Manager

## So sánh nhanh

| | Mid | Senior | Principal | Cloud Manager |
|---|-----|--------|-----------|---------------|
| Scope | 1–2 services | Domain / vài team | Org platform | Cloud estate + budget |
| Deliverable | Pipeline xanh | Chuẩn hóa team | Golden path + ADR | Policy, cost, vendor |
| Incident | Follow runbook | Lead SEV2 | SEV1 + systemic fix | Comms + vendor SLA |
| People | Pair | Mentor 1–2 | Guild / hiring bar | Manager + skip-level |
| Time horizon | Sprint | Quý | 2–4 quý | Năm tài chính |

## Tự chấm (1–5 mỗi mục)

Copy vào `portfolio/self-assessment.md`:

- [ ] IaC multi-env  
- [ ] CI/CD + DevSecOps gates  
- [ ] K8s hoặc ECS production  
- [ ] Multi-account / IAM  
- [ ] Observability + SLO  
- [ ] Incident leadership  
- [ ] Cost awareness / tagging  
- [ ] Viết ADR  
- [ ] Mentoring  
- [ ] Nói chuyện stakeholder non-tech  

**Gợi ý:** trung bình ≥ 3.5 và không mục nào = 1 trước khi apply Principal; Cloud Manager cần điểm cao FinOps + governance + communication.

## 90 ngày đầu ở role Principal (mẫu)

| Ngày | Focus |
|------|-------|
| 1–30 | Map hệ thống, pain, cost top 10, on-call health |
| 31–60 | 1 golden path MVP, 2 ADR lớn, SEV runbook chuẩn |
| 61–90 | Adoption metric, FinOps alert, roadmap quý sau |
