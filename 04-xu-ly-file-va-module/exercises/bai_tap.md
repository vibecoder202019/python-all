# Bài tập Module 04

## Bài 1: Đọc file và đếm từ (Dễ)
Đọc file text, đếm số dòng, số từ, từ xuất hiện nhiều nhất.

## Bài 2: Chuyển CSV → JSON (Trung bình)
Đọc file CSV sinh viên, chuyển sang JSON với thêm field `average`.

## Bài 3: Log Analyzer (Trung bình)
Parse file log dạng `[2024-01-15 10:30:00] ERROR: message`, thống kê theo level.

## Bài 4: Tạo package (Khó)
Tạo package `mycalc` với module `basic.py` (add, sub, mul, div) và `__init__.py` export functions.
