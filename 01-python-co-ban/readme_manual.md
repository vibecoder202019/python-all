# Hướng dẫn chạy Manual — Module 01: Python cơ bản

> Copy từng lệnh và chạy **tuần tự**. Module này **không có script automation** — mỗi bước = một file ví dụ.

## Mục đích

Hiểu luồng học: biến → điều kiện/vòng lặp → hàm → list comprehension.

## Điều kiện

- Python 3.10+
- Terminal

## Bước 0: Vào thư mục module

```bash
cd learn-python-ai/01-python-co-ban
```

## Bước 1: Biến và kiểu dữ liệu

```bash
python examples/01_bien_va_kieu_du_lieu.py
```

**Kỳ vọng:** In ra các kiểu `int`, `float`, `str`, `bool` và phép toán cơ bản.

## Bước 2: Điều kiện và vòng lặp

```bash
python examples/02_dieu_kien_va_vong_lap.py
```

**Kỳ vọng:** In kết quả `if/elif/else`, `for`, `while`.

## Bước 3: Hàm và lambda

```bash
python examples/03_ham_va_lambda.py
```

**Kỳ vọng:** In kết quả hàm thường, default args, lambda.

## Bước 4: List comprehension

```bash
python examples/04_list_comprehension.py
```

**Kỳ vọng:** In list được tạo bằng comprehension và dict comprehension.
