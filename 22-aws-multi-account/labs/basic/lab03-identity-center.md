# Lab 03 — IAM Identity Center (Console)

1. Enable **IAM Identity Center** (management)
2. Create user `dev.engineer`
3. Group `DevOps` → add user
4. Assign group to **Dev account** — Permission set `ViewOnlyAccess` (lab an toàn) hoặc PowerUser
5. Login portal URL → access Dev account

## Pass

User SSO vào Dev account không cần IAM access key.
